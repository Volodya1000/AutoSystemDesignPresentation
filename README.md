# AutoSystemDesignPresentation

Исходный код презентации AutoSystemDesign на LaTeX Beamer.

## Компиляция

Требуется дистрибутив LaTeX с поддержкой LuaLaTeX, пакет Beamer и шрифты Arial и Consolas.

```bash
lualatex presentation.tex
lualatex presentation.tex
```

Повторный запуск помогает обновить нумерацию и внутренние ссылки. Сгенерированный PDF не хранится в репозитории.
