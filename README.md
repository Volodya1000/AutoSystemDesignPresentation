# AutoSystemDesignPresentation

Исходный код презентации AutoSystemDesign на LaTeX Beamer.

## Компиляция

Для локальной сборки нужен LuaLaTeX, пакет Beamer и шрифты DejaVu Sans / DejaVu Sans Mono (или совместимые).

```bash
lualatex presentation.tex
lualatex presentation.tex
```

Повторный запуск помогает обновить нумерацию и внутренние ссылки.

## CI и PDF

GitHub Actions автоматически компилирует `presentation.tex` в PDF при каждом push в `main`, для каждого pull request и вручную через вкладку Actions.

- В pull request из этой же репозитория сгенерированный `presentation.pdf` автоматически коммитится в ветку PR, если его содержимое изменилось, поэтому он виден в **Files changed**.
- При push в `main` обновлённый `presentation.pdf` автоматически коммитится в корень репозитория, если файл изменился.
- Каждый успешный запуск также публикует PDF как артефакт `AutoSystemDesignPresentation-pdf` на 30 дней. Артефакт доступен на странице запуска во вкладке Actions.

## Изображения для слайдов-примеров

Добавьте в каталог `images/` файлы:

- `input_yaml.png` — изображение примера входного YAML-сценария.
- `c4_example_1.png` и `c4_example_2.png` — два примера C4-диаграмм, расположенные рядом на одном слайде.
- `sequence_example_1.png` и `sequence_example_2.png` — примеры диаграмм последовательностей на отдельных слайдах.
- `swagger_ui.png`, `swagger_example_2.png` и `swagger_example_3.png` — три примера интерфейса или спецификации Swagger.

Если файл отсутствует, вместо изображения на слайде отображается заглушка с ожидаемым путём. Файлы изображений добавляются вручную и не генерируются при сборке презентации.

## Содержание презентации

Презентация включает описание входных данных и результатов AutoSystemDesign, извлечение требований из документов, генерацию и проверку архитектуры, модель C4, валидаторы диаграмм и REST API. Пример YAML размещается отдельным изображением, чтобы сохранить читаемость слайда. На титульном слайде указано имя автора: Дичковский Владимир.
