# AutoSystemDesignPresentation

Краткая презентация AutoSystemDesign для коллег и системных архитекторов.

**Основная история:** BRD заказчика → извлечение и проверка требований → первая версия архитектуры, сценарии взаимодействия, REST API и оценка нагрузки.

Презентация состоит из 10 слайдов. Вместо технических подробностей в ней показаны пример бизнес-требований и существующие примеры результатов генерации. Примеры диаграмм из репозитория не выдаются за результаты запуска именно показанного BRD.

## Содержание

1. AutoSystemDesign и автор: Дичковский Владимир.
2. Что инструмент получает и создаёт.
3. Пример BRD системы обмена сообщениями.
4. Этапы обработки требований с подтверждением исходными цитатами.
5. Пример архитектурной диаграммы C4.
6. Пример диаграммы последовательностей.
7. Пример Swagger UI.
8. Анализ нагрузки и результаты в JSON/PDF.
9. Программные проверки результата.
10. Реализованные возможности и следующий шаг.

## Компиляция

Требуются LuaLaTeX, Beamer и шрифты DejaVu Sans / DejaVu Sans Mono.


~~~bash
lualatex -interaction=nonstopmode -halt-on-error presentation.tex
lualatex -interaction=nonstopmode -halt-on-error presentation.tex
~~~

## CI и PDF

GitHub Actions компилирует PDF на каждом pull request и push в main. Для pull request из этого же репозитория обновлённый `presentation.pdf` добавляется в ветку автоматически. PDF также доступен в артефактах запуска Actions.

Состояние реализованных возможностей сверено с основной веткой [AutoSystemDesign](https://github.com/Volodya1000/AutoSystemDesign). Презентация намеренно описывает сценарий для аудитории, а не внутренние детали конфигурации и развёртывания.
